This week, I completed the second AI-powered study tool for StudySync: **Flashcards V1**! After spending the previous week juggling a heavier-than-usual workload, I was finally able to spend more time developing and testing the application.

Unlike the Review Guide, which organizes and summarizes course material, Flashcards focuses on **active recall** by generating questions and answers from the student's NLP notes.

<!--more-->

# **What I Worked On**

I started by connecting the Flashcards page to the existing Gemini API integration. Using Python and Streamlit, I created a function that sends the student's course notes to Gemini and requests up to ten flashcards in a structured JSON format.

Once the flashcards were generating successfully, I built the interface so students could:

- Generate flashcards from their submitted notes.
- Reveal or hide answers to test their recall.
- Navigate between flashcards using Previous and Next buttons.
- Shuffle the existing flashcards without making another API request.
- Switch between study tools without losing their generated flashcards.

I also spent time improving the overall interface, including the layout, spacing, navigation, and appearance of the flashcards.

# **Prompt Engineering and Testing**

One of the biggest challenges was getting Gemini to generate a useful variety of questions without becoming repetitive.

My initial prompt generated ten flashcards, but several questions covered nearly identical information. I revised the prompt to prioritize distinct concepts and reduce redundancy, but that version became too restrictive and generated only four flashcards from the same notes.

After another round of revisions, I settled on a prompt that better balanced question quality, topic coverage, and the number of generated flashcards.

I tested the feature using two sets of NLP course notes.

The first test covered foundational topics such as tokenization, n-grams, stemming, and lemmatization. The final prompt generated seven relevant flashcards without the excessive repetition I had seen earlier.

For the second test, I used longer notes covering Word2Vec, cosine similarity, TF-IDF, and BM25.

This test generated **10 flashcards covering all eight major concepts** from the original notes. All ten questions and answers were consistent with the source material, and there was minimal repetition.

Some questions still combined multiple concepts into a single flashcard, which is something I may want to improve in a future version. However, I was happy with the results for the first implementation.

# **Improving Navigation and Session State**

Another challenge this week involved managing Streamlit's session state.

I wanted students to move between the Review Guide and Flashcards without having to regenerate their study materials. However, I also wanted Flashcards to return to the first question with the answer hidden whenever students navigated back to the page.

Initially, Streamlit preserved everything, including the last flashcard viewed and whether its answer was visible.

I experimented with changing the navigation buttons, but that introduced some inconsistencies in the interface. Eventually, I implemented a page-tracking function that detects when students return to Flashcards from another page.

This allowed me to preserve the generated deck while resetting the viewing position, without changing the appearance of the navigation links.

I also updated the application so that changing the original course notes resets previously generated study materials.

# **AI-Generated Content and Accuracy**

One concern that came up during testing was the accuracy of student-provided notes.

StudySync generates its flashcards from the submitted material, but that does not necessarily mean the original notes are correct. If a student provides incorrect information, the generated flashcards may reproduce those inaccuracies.

To address this, I added a notice explaining that the study tools do not independently fact-check the submitted notes. The application recommends starting with the Review Guide, which includes a section for flagging information that may need further verification.

This does not eliminate the possibility of incorrect information, but it makes the limitation clearer to students.

For now, I am considering **Flashcards V1 complete**. There are still improvements I could make, particularly around question focus and additional testing, but I want to prioritize completing the remaining study tools before revisiting earlier features.
