This week I reached one of the first major technical milestones for StudySync: connecting the application to an LLM API and generating the first AI-powered study resource. I connected StudySync to Google's Gemini API and used NLP course notes saved in the application as context to generate a Review Guide.

Last week, the Review Guide page was only a placeholder. This week, it became the first functional AI-powered study tool in StudySync.

<!--more-->

# **What I Worked On**

I started by connecting StudySync to the Gemini API. This was my first time integrating an LLM API into an application, so part of the process involved learning how to configure the API, securely manage the API key, send prompts and course material to the model, and display the generated response inside Streamlit.

Once the connection was working, I focused on the Review Guide. Rather than asking Gemini to simply summarize the notes, I created a prompt that gives the model instructions about how the guide should be organized and requires it to base the response on the student's provided course material.

This introduced the prompt and context design portion of the project that I had planned for in my proposal. The student's notes provide the context, while the prompt defines the task and expected structure of the generated Review Guide.

# **Evaluating the Review Guide**

Getting Gemini to generate a Review Guide was only the first step. I also wanted a way to evaluate whether the generated guide actually preserved the important information from the student's notes.

For this evaluation, I created a small rubric inspired by ideas from **SummEval** and **QAGS**, two approaches used to evaluate generated summaries. I adapted those ideas to StudySync rather than trying to reproduce either evaluation method directly.

I evaluated each generated Review Guide on four criteria:

* **Accuracy** - Does the guide correctly represent the source notes?
* **Coverage** - Does it include the important concepts and supporting information?
* **Relevance** - Does it stay focused on useful study material from the notes?
* **Organization** - Is the information structured clearly enough to study from?

Each category was scored from 1–5.

I also used a QAGS-inspired question test. For each set of source notes, I wrote five questions that should be answerable from the original material and then checked whether those same questions could be answered using only the generated Review Guide. This gave me another way to check whether important information had been lost during generation.

# **Testing and Revising the Prompt**

I first treated the original Review Guide prompt as **Version 1 (V1)** and tested it using several sets of my NLP course notes.

Overall, V1 performed well. Across the initial tests, it scored **97/100** on the evaluation rubric, and all **25/25 source-based questions** could still be answered from the generated guides.

However, the evaluation also showed where the prompt could improve. In particular, some examples and technical details were being simplified or omitted. This mattered for NLP notes because details such as formulas, notation, operators, and examples can be important when studying.

For **Version 2 (V2)**, I revised the prompt to explicitly tell Gemini to preserve:

* Important examples
* Technical details
* Formulas and notation
* Symbols and operators
* The original meaning of the source material

I then repeated the evaluation using the revised prompt. V2 scored **100/100** on the rubric while still preserving **25/25 source-based answers**.

The improvement was small numerically, but the comparison was useful because it showed that more specific prompt instructions helped preserve technical details and supporting examples without reducing the guide's ability to answer questions from the original notes.

# **Flagging Information for Review**

One additional issue became clear while working on the Review Guide: student notes are not guaranteed to be correct.

I do not want StudySync to silently treat everything in the notes as factual, but I also do not want the model rewriting the student's material without telling them.

For **Version 3 (V3)**, I added a section called **Notes to Review for Correctness**. The goal is for StudySync to preserve the student's notes while separately flagging information that may be unclear, contradictory, or worth verifying.

To test this behavior, I intentionally added two incorrect statements to a set of Tokenization notes. The generated Review Guide successfully flagged **2/2 intentional issues** for review.

During testing, I noticed that Gemini sometimes went beyond flagging the information and suggested what it believed the correction should be. That is something I want to continue monitoring because the goal of this feature is to make students aware of possible problems without encouraging them to automatically trust an AI-generated correction.

# **Challenges**

Working with an external LLM API also introduced a new type of problem compared with the local Streamlit prototype. During testing, Gemini occasionally returned a **503 UNAVAILABLE** error because the model was experiencing high demand.

The error was temporary, but it was a useful reminder that StudySync now depends on an external service that may not always respond successfully. Handling API failures more gracefully is something I can consider as the application develops.

# **Next Steps**

At this point, I am happy with the Review Guide as the first completed StudySync study tool. The evaluation helped me move beyond simply checking whether the AI could generate something that looked like a study guide and gave me a more structured way to compare prompt changes.

For now, I am going to stop iterating on the Review Guide and move on to another StudySync tool. My next focus will likely be **Flashcards**, where I can apply what I learned about prompt design, grounding generated content in the student's notes, and evaluating AI-generated study material.

The Review Guide can always be revisited later as I learn more from building and testing the other StudySync tools.
